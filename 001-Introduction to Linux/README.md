# 001 — Introduction to Linux 🐧

This section introduces Linux, its history and relationship with UNIX, open-source principles, the Linux directory hierarchy, and installing a Linux distribution in a virtual machine.

These notes are part of my Linux learning journey and cybersecurity / OSCP preparation. They focus on building practical Linux fundamentals that are useful for administration, troubleshooting, and authorized security labs.

## 🎯 Learning Objectives

- Understand what Linux is and how it relates to UNIX.
- Learn the basics of open-source software and Linux distributions.
- Recognize the purpose of key directories such as `/etc`, `/home`, `/var`, `/usr`, and `/tmp`.
- Understand the basic steps involved in installing Linux in a virtual machine.
- Build a foundation for Linux command-line work and further system administration topics.

## 🧪 Practice Checklist

- [ ] Explain the difference between the Linux kernel and a Linux distribution.
- [ ] Describe key characteristics of open-source software.
- [ ] Identify common Linux filesystem directories and their purposes.
- [ ] Install or boot a Linux virtual machine in a lab environment.
- [ ] Open a terminal and practice basic navigation commands such as `pwd`, `ls`, and `cd`.

## 🧰 Suggested Lab Setup

- A virtualization platform such as VirtualBox
- A Linux distribution for learning (use a supported distribution suitable for your hardware and course)
- A snapshot or backup before experimenting with system settings

## 🔐 Why This Matters for Cybersecurity

Linux fundamentals are essential for understanding servers, permissions, services, logs, networking, and command-line tooling. These skills provide a base for penetration testing and OSCP preparation.

> **Practice responsibly:** Perform experiments only on systems you own or are explicitly authorized to use.
