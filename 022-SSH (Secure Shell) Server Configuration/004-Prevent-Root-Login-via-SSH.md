#  Prevent-Root-Login-via-SSH

## 🔒 Prevent Root Login via SSH

Restricting root login over SSH is a recommended security practice to reduce potential attack surfaces and enforce the use of individual user accounts.

---

## 📝 Edit the SSH Configuration

### ✔️ You can define `PermitRootLogin no` in either:

* The **main SSH configuration file**, or
* A **separate override file**

---

## 🟦 Option 1: Edit the Main Config File

```bash
vim /etc/ssh/sshd_config
```

Add or update:

```bash
PermitRootLogin no
```

---

## 🟩 Option 2: Override Using a Drop-In File

Create or edit a drop-in config file for modular management (preferred on modern systems):

```bash
vim /etc/ssh/sshd_config.d/01.permitrootlogin.conf
```

Add the directive:

```bash
PermitRootLogin no
```

> 📝 *If this file was generated by an installer (e.g., Anaconda), feel free to edit or delete it as appropriate for your use case.*

---

## ✅ Step 2: Validate Configuration

Check for duplicate or conflicting directives:

```bash
grep -ri "PermitRootLogin" /etc/ssh/sshd_config.d/
```

```bash
grep -ri "PermitRootLogin" /etc/ssh/sshd_config*
```
- Output
```
/etc/ssh/sshd_config:#PermitRootLogin prohibit-password
/etc/ssh/sshd_config:PermitRootLogin no
/etc/ssh/sshd_config:# the setting of "PermitRootLogin prohibit-password".
/etc/ssh/sshd_config.d/01-permitrootlogin.conf:PermitRootLogin no
```
---

## 🔄 Restart SSHD

After modifying the config, restart the SSH daemon:

```bash
systemctl restart sshd.service
```

---

## 🧪 Step 4: Test SSH Access

Use a non-root user to test connectivity (e.g., on a custom port):

```bash
ssh -p 2222 armour@192.168.1.21
```

> ⚠️ *Attempting to log in as **root** should now result in a **"Permission denied"* error.*

---

## 📘 Example SSH Configuration Snippet (`/etc/ssh/sshd_config`)

### 📂 `/etc/ssh/sshd_config`

```bash
Include /etc/ssh/sshd_config.d/*.conf
Port 2200
ListenAddress 192.168.1.21
PermitRootLogin no
AuthorizedKeysFile .ssh/authorized_keys
Subsystem   sftp   /usr/libexec/openssh/sftp-server
```

---

### 📂 `/etc/ssh/sshd_config.d/01.permitrootlogin.conf`

```bash
PermitRootLogin no
```
