
# 🖥️ Remmina

* **Remmina** is a modern, feature-rich remote desktop client. ✨
* It supports multiple protocols including **RDP, VNC, NX, XDMCP, and SSH**. 🔐
* Highly recommended for managing multiple connections and profiles. 🧩

---

## 📌 Install Remmina On CentOS/RHEL

Install Remmina using **YUM**:

```bash
yum install remmina
```

---

## 📌 Install Remmina On Debian/Ubuntu

Install Remmina using **APT**:

```bash
apt install remmina
```

---

## 🚀 Launch Remmina

After installation, you can launch Remmina from the terminal:

```bash
remmina
```

Or find it in your desktop environment’s application menu. 🖱️

---

## 📝 Additional Notes

* **🔥 Firewall Settings:** Ensure your firewall allows connections on **RDP (port 3389)** and **VNC (ports 5900+)**.
* **🔐 SSH Tunneling:** For secure VNC or RDP sessions over the internet, consider using **SSH tunneling**.
