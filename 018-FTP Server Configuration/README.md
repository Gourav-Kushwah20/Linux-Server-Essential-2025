## 🚀 Purpose
These guides help you understand how to:
- Configure **anonymous and authenticated** FTP access
- Allow or restrict users and root login
- Manage user home directory access on FTP
- Configure custom FTP paths and directory structures
- Use basic FTP client commands for uploading/downloading files

## 📌 Notes
- Based on **vsftpd**, one of the most secure FTP servers available
- Works on most Linux distributions (Debian, Ubuntu, RHEL, CentOS)
- Includes practical examples and security considerations
